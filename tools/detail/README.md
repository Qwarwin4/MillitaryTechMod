Detail maps used by `uvbake.py` as a layer on top of the painted textures: grime streaks, blotches, scratches,
chipped-paint shapes, steel, canvas weave, rubber and rust.

Made from textures by [ambientCG](https://ambientcg.com) (CC0 1.0, public domain): SurfaceImperfections003,
SurfaceImperfections008, Scratches003, Scratches005, PaintedMetal011, Metal063, Fabric030, Rubber004, Rust007.
Reduced to 256x256 greyscale (rust stays in colour).
